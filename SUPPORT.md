# Support

`@global-torque/sdk` uses ordinary semantic versions. Before `1.0`, breaking
changes require a new minor version and are recorded in `CHANGELOG.md`; patch
releases preserve the supported API. Ordinary releases are published to `latest`.

Open reproducible defects and feature requests at:

https://github.com/global-torque/sdk/issues

Include the package version, runtime and package-manager versions, the imported
subpath, and a minimal reproduction. Do not include credentials, wallet secrets,
customer data, or private service URLs.

Security reports must use the private process in `SECURITY.md`, not a public
issue.
